# Test Cases Suite

## 1. High-Level Test Suite Overview
This test suite defines the concrete test cases for the User Acceptance Testing (UAT) phase of the Pro Guitar Tuner App Beta (Version 6.0.9). It translates our defined test conditions into structured validation templates. 

To maintain strict alignment with the Test Plan constraints, advanced UI layout, notation, and dashboard toggle test cases are restricted to the **Samsung Galaxy S25 FE**. Cross-device validation for pitch checks and screen rotation is explicitly mapped across all three physical testing endpoints (**Samsung S25 FE, Samsung S21 FE, and Samsung A53 5G**).

---

## 2. Test Cases Specification

### TC-CASE-PT-01: Synthetic Pitch Frequency Accuracy Matrix
* **Description**: Verify the chromatic pitch detection algorithm across all 12 prioritized instrument tuning profiles using a pure wave synthesizer.
* **Target Test Condition**: `TC-PT-01` through `TC-PT-12`
* **Preconditions**: 
  * App is freshly initialized on the target device.
  * Device microphone permissions are granted.
  * Ambient noise floor is verified between 10 dB and 30 dB via the primary calibration node.
* **Test Data Category**: 
  * Synthetic audio signals matching the 12 target tuning tables (frequencies ranging from C2 [65.41 Hz] to F4 [349.23 Hz]) generated by the online tone generator platform.
* **Expected Result**: The app accurately captures the incoming acoustic frequency on all three devices, matching the pitch value to the correct string note indicator within an acceptable precision boundary.
* **Priority**: High

### TC-CASE-UI-01: Tuning Note Profile Layout Validation
* **Description**: Verify that the text indicators on the dashboard accurately display the correct note letters for Standard tuning.
* **Target Test Condition**: `TC-UI-01`, `TC-UI-02`
* **Preconditions**: 
  * Test execution is limited to the **Samsung Galaxy S25 FE** profile only.
  * App is active and set to the default view.
* **Test Data Category**: The Standard tuning profile stored within the app selection menu.
* **Expected Result**: The tuning profile instantly updates the on-screen target note array. No text clipping, overlapping interface elements, or incorrect note names are observed.
* **Priority**: High

### TC-CASE-UI-02: Screen Orientation Scaling and Stability
* **Description**: Verify that the application UI scales its dimensions correctly and remains stable when shifting device orientation under active load.
* **Target Test Condition**: `TC-UI-03`, `TC-UI-04`
* **Preconditions**: 
  * Executed across all three test devices (**Samsung S25 FE, Samsung S21 FE, Samsung A53 5G**).
  * App is running in "Standard Tuning" mode with an active microphone input stream.
  * All 3 devices is set to unlock auto rotation.
* **Test Data Category**: Physical hardware rotation inputs (0-degree portrait to 90-degree landscape shifts).
* **Expected Result**: The interface adjusts seamlessly to the new screen dimensions without resetting calibration parameters, dropping active text strings, freezing, or terminating unexpectedly.
* **Priority**: High

### TC-CASE-UI-03: Accidental Notation Conversion Processing
* **Description**: Verify that sharp (#) notes translate cleanly to flat (♭) equivalents when alternating the notation layout switch.
* **Target Test Condition**: `TC-UI-05`
* **Preconditions**: 
  * Restricted to the **Samsung Galaxy S25 FE**.
  * Application is set to a profile containing accidentals (e.g., Half-step down D#).
* **Test Data Category**: Menu notation format toggle state change (Sharp vs Flat configuration).
* **Expected Result**: The interface elements update their displayed note labels instantly (e.g., converting D#2 visually to E♭2), confirming consistent backend processing logic.
* **Priority**: Medium

### TC-CASE-UI-04: Tuning Dashboard Component Overlays
* **Description**: Verify the visual accuracy and responsiveness of individual feature overlays on the master dashboard panel.
* **Target Test Condition**: `TC-UI-06`, `TC-UI-07`, `TC-UI-08`, `TC-UI-09`
* **Preconditions**: 
  * Restricted to the **Samsung Galaxy S25 FE**.
  * Standard Tuning profile selected; baseline controls active.
* **Test Data Category**: Manual adjustments of dashboard metric toggles (Hz on/off, Cent gauge on/off, Solfège conversion layout).
* **Expected Result**: 
  * Activating the numeric display outputs a live, floating frequency value in Hertz.
  * The Cent offset gauge shifts dynamically to indicate flat or sharp input variances.
  * The graphic interface clearly highlights the specific target guitar string line matching the audio.
  * Activating the Solfège system successfully overwrites letter labels with corresponding "Do-Re-Mi" values.
* **Priority**: High

### TC-CASE-INT-01: Empirical Physical Instrument Acoustic Capture
* **Description**: Verify the performance and adaptability of the internal microphone pick-up tracking using live 6-string physical guitar variants.
* **Target Test Condition**: `TC-INT-01` through `TC-INT-04`
* **Preconditions**: 
  * Executed on the **Samsung Galaxy S25 FE**.
  * App configured to Standard Tuning.
  * Physical instruments tuned close to baseline parameters.
* **Test Data Category**: 
  * Physical structural instrument properties: 6-String Steel Acoustic, 6-String Nylon Classical, Unamplified Electric, and Clean-Amplified Electric.
  * Environmental sound floor profiles: Quiet Studio (10–30 dB) vs High Noise Environment (background chatter simulation).
* **Expected Result**: The tuner captures physical string vibrations from all four guitar styles in both environments, processing the note accurately without getting blocked by ambient background sound.
* **Priority**: High
